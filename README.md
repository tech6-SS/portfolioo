# portfolioo

A clean portfolio website template, built with HTML/CSS/JS.

## Files

- `index.html` — landing page content
- `styles.css` — user interface styling
- `script.js` — interaction and simple contact form behavior

## Run locally

1. Open `index.html` in your browser.
2. Or use a local server (recommended):
   - `python3 -m http.server 8000`
   - Visit `http://localhost:8000`

## Deploy on GitHub Pages

1. Push to `main` (already done).
2. The workflow `.github/workflows/github-pages.yml` builds and deploys to `gh-pages` branch on each push to `main`.
3. Enable Pages in repository settings:
   - `Settings` > `Pages` > Source: `gh-pages` branch `/ (root)`.
4. Your site will be published at: `https://<your-username>.github.io/portfolioo/`
